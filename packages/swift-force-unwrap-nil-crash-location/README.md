# Swift 강제 해제 nil 크래시의 파일명과 줄 번호 확인

옵셔널 값에 `!`를 붙여 강제 해제했을 때 nil이면 런타임에 트랩이 발생한다. 이때 콘솔에 찍히는 `Fatal error: Unexpectedly found nil while unwrapping an Optional value` 메시지에 파일명과 줄 번호가 함께 나온다.

이 예제는 세 가지 경로에서 nil을 강제 해제한다. 딕셔너리 subscript 조회, 중첩된 구조체 프로퍼티 접근, 함수 반환값이다. 각 경로는 `main.swift`에서 별도 함수로 나뉘어 있다.

실행 시 첫 번째 함수에서 멈추는 것이 기본 흐름이다. 주석 처리된 호출을 하나씩 살려서 실행하면 메시지의 줄 번호가 어느 `!` 위치를 가리키는지 확인할 수 있다.

메시지의 줄 번호를 소스와 대조할 때는 강제 해제 연산자가 놓인 줄을 기준으로 본다. 여러 줄에 걸친 체인에서는 `!`가 있는 줄이 보고되는지, 체인 시작 줄이 보고되는지도 같이 본다.

이 예제에서 확인한 것은 메시지 형식과 줄 번호 대응뿐이다. 다른 Swift 버전이나 빌드 설정에서 같은 문구가 그대로 나오는지는 확인하지 않았다.
